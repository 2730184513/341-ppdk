# PPDK Project Instructions

Check the branch, worktree status, and assigned task before making changes. Follow the [contribution workflow](docs/AGENT-WORKFLOW.md) and check [module ownership](docs/TEAM-OWNERSHIP.md) when touching shared files.

Use your own Git identity. Keep commits, pull requests, documentation, and user-facing content in English. Describe what changed and report only checks you actually ran. Keep passwords, sessions, and local runtime configuration out of Git.
