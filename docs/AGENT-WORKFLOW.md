# Contribution Workflow

Start a short-lived branch from the team-approved commit on `main`. Keep each commit focused on a reviewable change, and open one pull request per branch.

Include the affected workflow, validation steps, observed results, and tested commit in the pull request. Ask the designated reviewer to review the current head. Resolve comments before the coordinator merges with a merge commit.

Check the [classroom integration sequence](INTEGRATION-ORDER.md) after changing cross-module behavior. Use the [project backlog](TEAM-TASKS.md) for follow-up work outside the current release.
